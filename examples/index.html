Write the CSS you actually mean

StratumSS is a utility-first CSS framework whose class names read like the declarations they produce. A build-time compiler scans your templates and emits only the rules you use.

npx stratumss build padding-10px_20px

Readable by default

items-vertical-center maps to align-items: center. No abbreviations to memorise.

Verified values

padding-4p fails the build with a suggestion instead of shipping a broken declaration.

Only what you use

The compiler emits one rule per class found in your source files — nothing more.

What this page compiled to

stratumss build examples --output examples/stratum.css
